# Algorithmic Art Studio

Generative art workspace using p5.js — create seeded, reproducible algorithmic artwork.

## Quick Start

1. Open `index.html` in a browser to see the current artwork
2. Use seed controls to explore variations
3. Adjust parameters and colors in the sidebar
4. Click **Download PNG** to export

## Agents

| Agent | Description |
|-------|-------------|
| **art-consultant** | Creative director — understands your vision, recommends techniques |
| **code-generator** | Implementation specialist — produces p5.js code |
| **quality-reviewer** | Validation — checks code quality and visual standards |

## Skills

| Skill | Domain |
|-------|--------|
| **particle-systems** | Flow fields, boids, N-body, trails |
| **fractals-and-math** | Mandelbrot, Julia, L-systems, parametric curves |
| **nature-simulation** | Reaction-diffusion, cellular automata, DLA, waves |
| **color-and-composition** | Palette theory, layering, visual balance |

## Templates

Pre-built scenarios in `templates/`:

- **Mathematics** — Mandelbrot explorer, phyllotaxis spiral, Lissajous harmonics
- **Physics** — Flow field particles, wave interference, N-body gravity
- **Biology** — Reaction-diffusion, cellular automata, flocking boids
- **Geometry** — Voronoi tessellation, fractal tree, circle packing
