Wave Interference

Overlapping circular waves creating interference patterns. Multiple point sources emit sine waves that constructively and destructively combine across the canvas.

This artwork simulates the wave superposition principle from physics. Multiple point sources are placed at seeded random positions, each emitting circular sine waves. At every pixel, the algorithm computes the sum of all wave contributions based on distance from each source. Constructive interference (where waves align) produces bright peaks, while destructive interference (where waves cancel) creates dark troughs. The result is a mesmerizing moire-like pattern that varies entirely with source placement.
