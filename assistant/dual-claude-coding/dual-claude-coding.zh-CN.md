# 双 Claude 编程

两个 Claude 代理在你的代码库上进行结对编程：**Driver** 负责规划和审查，**Navigator** 负责实现和测试。

## 工作原理

- **Driver**（规划/审查者）：分析任务，分解步骤，审查实现，发现 Bug，指导下一步操作。不直接编写代码。
- **Navigator**（实现者）：接收指令，编写代码，运行测试，报告结果。指令不明确时主动询问。

两个代理通过消息中继系统交替通信，直到任务完成或达到轮次上限。

## 最佳实践

- 提供清晰、具体的任务描述
- 将工作区设为项目根目录
- Driver 会先制定计划，然后逐步指导 Navigator
- 两个代理共享同一文件系统——一方的修改对另一方可见
- 当任一代理发出完成信号或达到轮次上限时，会话结束
